# 智能厨房管家 Agent Demo

浏览器运行的本地 Web Demo，包含首页、冰箱库存、菜谱和采购清单。

## 本地预览

```sh
ruby server.rb
```

打开 <http://127.0.0.1:4567>。库存、偏好、菜单、菜谱草稿、我的菜谱和做饭进度保存到本机 `data.json`；没有账户同步能力，不支持跨设备同步。不要将个人数据或密钥提交到仓库。

## 菜谱体验

- “发现菜谱”把自然语言需求（食材、菜品、口味、餐次、人数、时间和做法）交给服务端 DeepSeek 解析并生成结构化菜谱，不再把整句话当作菜名搜索。已提供的食材可不在冰箱台账中；生成卡片仍会提示库存核对，选菜不扣库存。推荐结果会在本地复核餐次、时间、厨具、过敏/忌口及食材要求；请求失败保留原方案并提供重试，支持取消，不会静默改用本地预设伪装成 AI。
- “换点新花样”不按库存匹配或排序。仓库没有联网热度检索服务，因此结果明确标为“AI创意灵感 · 未核验近期热度”，不声称实时流行或虚构来源链接；未配置网页检索时无法提供可核验的近期热度。
- 首页提问、发现需求、我的菜谱检索、冰箱食材检索、添加库存和快速添加采购均可使用统一语音控件。语音通过浏览器 Web Speech API 识别，权限、支持情况取决于浏览器；应用不上传或保存录音，浏览器语音服务可能按自身规则处理音频。识别后可编辑、追加或替换，需用户手动提交。
- “我的菜谱”支持保存、搜索、按标签/来源筛选和编辑。导入链接、分享文字或图片会建立待核对草稿；当前没有菜谱解析/图片识别服务，不会抓取受限平台内容，也不会把链接保存说成已解析。
- 用户可选择一套菜谱加入本餐，或在菜单中继续添加多道菜；有未完成的菜单时，选另一顿会先询问是否替换。整餐流程按菜谱依赖排序，共享生米只安排一次且用量汇总，按顺序执行；缺少明确步骤用时的整餐只显示“总用时待估”，不编造分钟数。制作途中可直接选择“我已做完”，不必逐步打卡。
- 查看、加入菜单和开始制作不扣库存。完成后默认以参考用量汇总已选菜品的食材；用户明确点击“从库存按参考量更新”才扣减已记录库存。用户可切换手动用量、标记全部或部分食材为新买、暂不更新不确定项目，并按需补记新购剩余。菜品勾选改变时会重新汇总共享食材；清水不进入库存确认。确认和补记入库在服务端作为同一幂等操作提交，完成页提供更新数量与撤销入口；撤销会核对受影响库存的完整快照，库存已被后续修改时拒绝覆盖。
- 预设菜谱分列主要食材、辅料和调味料；原文未提供的基础调味项只作为可编辑的“建议补充”，并标记适量/未知，不换算成精确用量。单位不兼容或数量不确定时不计算精确缺口。

## 未接入能力与图片清单

菜谱 AI 推荐使用服务端 `DEEPSEEK_API_KEY` 配置。当前未接入网页检索、菜谱链接解析、图像识别、AI 图片生成或 AI 步骤图服务；首页自由问答与菜谱生成是两个独立的 DeepSeek 请求。缺图时文字流程仍可使用。

当前 16 道预设菜谱都没有已核验来源与授权的匹配成品照片，封面紧凑显示“菜品图片待补充”，不会展示无效的图片生成按钮；步骤图也未补齐。缺图时仍展示菜名、用量和文字操作。导入的用户图片可作为封面，并标注为用户上传；其他图片来源、署名和授权信息需由用户核实填写。AI 参考图/步骤示意在生成服务接入前不会标记为已生成。

缺少封面的预设菜谱：番茄鸡蛋饼、香蕉牛奶燕麦碗、西兰花鸡蛋饼、鸡蛋蔬菜炒饭、番茄鸡蛋盖饭、西兰花鸡胸肉饭、鸡胸肉胡萝卜饭、西兰花鸡蛋饭、番茄炒蛋配米饭、鸡胸肉西兰花炒饭、鸡蛋炒饭配清炒西兰花、温牛奶配香蕉、小份鸡蛋饭、番茄蛋花汤、西兰花鸡蛋小煎饼、家常鸡蛋饼。

## 开发与验证

测试或并行预览时可将 `DATA_PATH` 指向临时 JSON 文件，并用 `PORT` 指定端口；默认仍使用项目根目录的 `data.json`。例如：

```sh
DATA_PATH=/tmp/demo5018-recipe-test.json PORT=4568 ruby server.rb
```

## 其他能力

首页自由问答可单独配置 DeepSeek。复制 `.env.example` 为 `.env` 并填写服务端 API Key；密钥只保存在服务端环境，不应写入前端资源。未配置时不影响本地菜谱流程。

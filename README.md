# 食光管家

食光管家是一个面向家庭食材管理的移动端 Web Demo，帮助用户查看冰箱库存、优先处理临期食材、管理采购清单，并根据库存获取菜谱建议。

## 产品说明

### 目标

减少食材遗忘和浪费，让家庭用户更方便地规划采购与日常烹饪。

### 主要功能

- **首页**：查看临期食材和采购清单入口、库存概况、每日菜品推荐，并向厨房管家提问。
- **我的冰箱**：按冷藏和冷冻查看库存，添加或编辑食材、数量、位置和到期日。
- **智能菜谱**：浏览根据库存生成的菜谱，查看所需食材和烹饪步骤，并收藏菜谱。
- **采购清单**：管理待买和已买食材，将已购食材同步到库存。
- **我的**：查看饮食偏好、忌口、临期提醒设置、收藏和最近历史。

### 首页信息顺序

首页依次展示临期与采购快捷入口、库存与营养提示、每日推荐、厨房管家问答，以及临期明细。采购清单入口只保留在页面顶部。首页视觉与交互细节见[首页使用说明](docs/home-usage.md)。

> 首页“库存营养均衡度”按内置标准份数估算库存类别覆盖与多样性，不是营养成分评估，也不代表个人健康状况。换算规则和限制见[首页使用说明](docs/home-usage.md)。

## 本地运行

### 环境要求

- Ruby
- DeepSeek API Key（使用 AI 菜谱和问答功能时需要）
- SerpApi Key（可选；配置 `SERPAPI_API_KEY` 后，新菜谱会自动搜索菜品图片并显示来源）

### 启动

1. 复制 `.env.example` 为 `.env`，填写 DeepSeek Key；如需自动搜索菜品图片，再填写 SerpApi Key。
2. 在项目目录运行：

   ```sh
   ruby server.rb
   ```

3. 在浏览器打开 <http://127.0.0.1:4567>。

## 项目文件

- `index.html`：页面骨架与底部导航。
- `app.js`：页面渲染、交互和 API 调用。
- `styles.css`：移动端页面样式。
- `server.rb`：本地 Web 服务和后端 API。
- `seed.json`：初始演示数据。
- `docs/home-usage.md`：首页功能和操作说明。

## 安全与数据

`.env` 与 `data.json` 应保持在本地，不要提交 API Key 或个人数据。`.env.example` 仅用于说明所需配置。

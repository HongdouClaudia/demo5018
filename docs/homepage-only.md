# 首页独立更新

基于 `main` 的 `4941b5bb668d9c6725b12a58b2c5c229e934c894`，仅更新首页。

## 首页变化

- 顶部提供需优先处理、采购清单两个入口；新鲜度沿用 main 的 `freshnessFor` 规则。
- 展示库存类别覆盖和标准份数估算，展开查看库存构成；不代表个人营养或健康状况。
- 每日推荐使用首页独立图片卡片，点击后进入原有菜谱详情。
- 厨房管家仍调用 main 原有问答流程。
- 饮食提示根据库存和待买项变化，可主动加入采购清单；失败时回滚本次新增项。

## 保持 main 的行为

冰箱、菜谱、我的、采购清单、共享导航、表单和 API 业务逻辑均保留 main 实现。首页专用代码放在闭包中；所有新增 CSS 选择器以 `.home-page` 开头。后端仅增加首页 JPG 静态文件读取和 MIME 类型，不增加在线搜图接口或 API Key 要求。

`server.rb` 的现有业务处理、`index.html`、`.env.example`、`seed.json` 和食材知识库不变；本地 `.env`、`data.json` 不提交。

## 验证

运行 `GIT_BIN=/path/to/git node tests/homepage-scope.test.cjs`。测试将非首页代码、原始 CSS、静态路由以外的后端代码逐字与基线比较，并比较相同数据下冰箱、菜谱和我的页面输出。基线通过 `HOMEPAGE_BASE_REF` 可覆盖。

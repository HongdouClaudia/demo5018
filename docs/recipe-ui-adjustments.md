# 菜谱体验调整

开发目录为 `demo5018-recipe`，分支为 `moonxiang1222-recipe`。保留当前未提交修改，没有合并 main 或推送。

## 当前行为

- 主按钮最小高度46px，普通按钮38px；小屏控制项可以换行，桌面按内容宽度排列。弹窗限制在视口内并允许正文滚动，制作页操作不再固定覆盖内容。
- 已确认过敏与忌口后自动沿用个人登记。发现页和已登记的个人设置均提供“无修改，与个人登记一致”，一次点击即可退出调整。
- 当餐只改人数、口味与厨具，默认不写入长期偏好；勾选“同时保存为个人偏好”才保存。临时设置不能覆盖过敏与忌口。首次缺少明确确认时仍登记一次。
- 完成制作后默认为一张参考记账卡。查看用量折叠；修改只打开“有道菜没做”“用了新买的”“用量不一样”中的一项。正常参考记账在完成卡只需一次明确提交。
- 取消菜品立即重新汇总共享用量；只勾选新买食材即可排除相应旧库存。混合来源必须明确填旧库存用量，或填写当前实际剩余。新购剩余为可选新批次。
- 快速盘点当前实际剩余以新基准保存，不重复扣减此前估算。多批次不能猜分配；不足、不明数量、状态存疑、单位不兼容项保持不变。
- 提交和撤销检查完整库存快照；全局版本防止过期页面覆盖后续修改。记账编号保证幂等；实际库存、完成摘要和菜单清理同一事务落盘。
- 锅铲进度条位于本餐标题下、步骤卡上。只有明确完成步骤才增加计数；查看、返回步骤不增减完成标记。状态持久保存，保留“我已做完”。

```sh

zsh ./预览菜谱分支.command
```

脚本默认4570端口，每次使用独立示例数据，不读取或修改正式库存。打开 `http://127.0.0.1:4570`。如端口被占用，执行 `PORT=4571 zsh ./预览菜谱分支.command`。
